# salary-service（工资结算服务）

问诊领域支撑服务之一：**工资结算**。

- **规划端口**：8097
- **规划数据库**：`shopdb_salary`
- **职责**：按周期结算医生与药师的报酬——计费口径（接诊量、审方量、排班出勤、处方量）汇总、结算规则引擎、出账与对账、结算单状态管理（生成 → 确认 → 已支付）；数据来源为问诊记录、处方管理、排班等上游服务的统计结果。
- **状态**：占位模块，暂无代码实现。具体实现要求见 [`harness/agents/salary-service.md`](../harness/agents/salary-service.md)。

> 问诊领域属于医疗买药问诊平台四大领域（商品 / 导购 / 问诊 / 订单）之一：上游接收导购领域转化来的问诊线索，问诊完成后向订单领域输出处方凭据。
