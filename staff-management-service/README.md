# staff-management-service（医生药师管理服务）

问诊领域支撑服务之一：**医生药师管理**。

- **规划端口**：8095
- **规划数据库**：`shopdb_staff`
- **职责**：医生与药师的档案管理——执业资质证照（医师执业证/药师资格证）、科室与职称、入驻审核流程、在职/停诊/离职状态生命周期；为分配医生、分配药师、排班、工资结算提供人员主数据。
- **状态**：占位模块，暂无代码实现。具体实现要求见 [`harness/agents/staff-management-service.md`](../harness/agents/staff-management-service.md)。

> 问诊领域属于医疗买药问诊平台四大领域（商品 / 导购 / 问诊 / 订单）之一：上游接收导购领域转化来的问诊线索，问诊完成后向订单领域输出处方凭据。
