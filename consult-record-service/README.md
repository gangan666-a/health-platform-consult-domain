# consult-record-service（问诊记录服务）

问诊领域核心服务之一：**问诊记录**。

- **规划端口**：8090
- **规划数据库**：`shopdb_consult_record`
- **职责**：问诊会话全过程留痕（文字/图片/处方事件）、医患沟通记录落档、问诊历史查询与归档，供问诊领域内其他服务与平台下游（订单领域纠纷仲裁、平台质检）取证使用。
- **状态**：占位模块，暂无代码实现。具体实现要求见 [`harness/agents/consult-record-service.md`](../harness/agents/consult-record-service.md)。

> 问诊领域属于医疗买药问诊平台四大领域（商品 / 导购 / 问诊 / 订单）之一：上游接收导购领域转化来的问诊线索，问诊完成后向订单领域输出处方凭据。
