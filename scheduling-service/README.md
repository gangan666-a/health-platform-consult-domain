# scheduling-service（排班服务）

问诊领域支撑服务之一：**排班**。

- **规划端口**：8096
- **规划数据库**：`shopdb_scheduling`
- **职责**：医生与药师的班次规划与发布（班次模板、周期排班、节假日特殊班）、可约容量计算（每班次最大接诊/审方量）、调班与停诊管理；是「分配医生/分配药师」判断人员在线可调度状态的唯一依据。
- **状态**：占位模块，暂无代码实现。具体实现要求见 [`harness/agents/scheduling-service.md`](../harness/agents/scheduling-service.md)。

> 问诊领域属于医疗买药问诊平台四大领域（商品 / 导购 / 问诊 / 订单）之一：上游接收导购领域转化来的问诊线索，问诊完成后向订单领域输出处方凭据。
