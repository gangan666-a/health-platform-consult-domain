# prescription-service（开处方服务）

问诊领域核心服务之一：**开处方**。

- **规划端口**：8091
- **规划数据库**：`shopdb_prescription`
- **职责**：医生在问诊会话中在线开具处方（诊断结论 + 药品明细 + 用法用量 + 医师签名），处方开立即绑定当前问诊会话；开方行为仅限已接诊且具备执业资质的医生发起。
- **状态**：占位模块，暂无代码实现。具体实现要求见 [`harness/agents/prescription-service.md`](../harness/agents/prescription-service.md)。

> 问诊领域属于医疗买药问诊平台四大领域（商品 / 导购 / 问诊 / 订单）之一：上游接收导购领域转化来的问诊线索，问诊完成后向订单领域输出处方凭据。
